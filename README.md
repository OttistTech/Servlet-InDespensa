🥫 InDespensa

InDespensa é um aplicativo inovador projetado para facilitar a organização da cozinha e a logística de pequenos negócios. Com ele, você pode gerenciar seu estoque de forma inteligente, evitar desperdícios e melhorar sua eficiência no dia a dia! 🚀

📌 Tecnologias Utilizadas

🔹 Java - Servlets para requisições web🔹 Banco de Dados SQL - Script de criação e gerenciamento🔹 DAO (Data Access Object) - Para operações CRUD🔹 Arquitetura Back-end - Desenvolvida com foco em escalabilidade🔹 Figma - Para design do aplicativo🔹 HTML & CSS - Para criação de landing pages e páginas CRUD🔹 Modelagem de Dados - Para estruturação do banco de dados

🎯 Funcionalidades Principais

✅ Cadastro, edição e remoção de produtos✅ Controle de estoque com alertas de baixa quantidade✅ Integração com sistema de pedidos✅ Geração de relatórios para previsão de consumo✅

🚀 Como Executar o Projeto

1️⃣ Clone o repositório:

 git clone https://github.com/seu-usuario/InDespensa.git

2️⃣ Configure o banco de dados utilizando o script SQL disponível na pasta database.3️⃣ Configure um servidor de aplicação compatível com Java Servlets (como Apache Tomcat).4️⃣ Compile e execute o projeto.
