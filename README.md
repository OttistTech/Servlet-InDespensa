InDespensa:


InDespensa é um aplicativo projetado para facilitar a organização da cozinha e a logística de pequenos negócios. Com funcionalidades de controle de estoque, gerenciamento de produtos e previsão de reposição, ele auxilia no planejamento e evita desperdícios.

Java (Servlets para requisições web)

Banco de Dados SQL (Script de criação e gerenciamento)

DAO (Data Access Object) para operações CRUD

Arquitetura Back-end desenvolvida com foco em escalabilidade

Figma para design do aplicativo

HTML & CSS para criação de landing pages e páginas CRUD

Modelagem de Dados para estruturação do banco de dados


Funcionalidades Principais:


Cadastro, edição e remoção de produtos

Controle de estoque com alertas de baixa quantidade

Integração com sistema de pedidos

Geração de relatórios para previsão de consumo
